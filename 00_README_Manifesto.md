# Экосистема FomAI — Архитектурная документация (v3.3)

## Манифест и три главных принципа
1. **Полная открытость:**
   - Базовая ОС строится поверх открытого исходного кода **AOSP (Android Open Source Project)** без привязки к закрытым проприетарным сервисам (de-Googled AOSP).
   - Разблокируемый загрузчик из коробки (включая расширенный инженерный режим на **FomAI Z0 DevIce**).
   - Открытые, читаемые форматы данных (`.ft` для текстовых/структурированных документов, `.faf` для мультимедийных пакетов, чистый Markdown и JSON-манифесты).
2. **Максимальная кастомизация:**
   - Модульная архитектура всех приложений и самой системы: ядро + подключаемые плагины + межсервисная шина событий (**FomAI Bus**).
   - Глубокая настройка тем оформления, звуковых паков, жестов, виджетов и характера системного ассистента **Morph AI**.
3. **Фирменные пасхалки везде:**
   - В настройках системы (тап по версии **FomAI OS** запускает ретро-терминал **1984 Edition**).
   - В **FomAI Music** (витрина «Выбор создателя» с **RADIO TAPOK**, пресет эквалайзера и девиз *«Найди себя здесь!»*).
   - В **FomAI Browser** (скрытый детектор омоглиф-доменов с отчётом о пойманных поддельных символах).
   - В **Morph AI** (фразы-триггеры с басовым голосовым фильтром и редкие философские реплики).
