# Модульная архитектура и ключевые приложения экосистемы

## Принцип модульности (Core + Plugins + FomAI Bus)
Все приложения экосистемы проектируются как конструктор, чтобы новые функции и сторонние сервисы добавлялись без переписывания основного кода:
1. **Ядро (Core):** Отвечает только за базовую механику (рендер, локальное хранение в открытых форматах, базовый UI).
2. **Плагины (Extensions):** Подключаемые модули (импортёры, эквалайзеры, графы связей, темы оформления, пасхалки).
3. **Межсервисная шина (`FomAI Bus` / Intents):** Единый контракт событий, позволяющий приложениям обмениваться данными (например, **FomAI Work** отправляет смены в календарь и берёт регламенты из **FomAI LB**).
4. **Адаптеры-коннекторы:** Сменные мосты для интеграции с внешними API, вики-движками, видеохостингами и локальными моделями.

## Ключевые приложения
- **FomAI Work:** Управление сменами и графиком команды с самопланированием:
  - Руководитель задаёт обязательное количество сотрудников/часов на каждый день недели и недельную норму часов каждого работника.
  - Каждое воскресенье команда сама распределяет смены с автопроверкой всех ограничений (нормы часов, ротация вечерних/выходных слотов, наличие опытного сотрудника, перерывы между сменами), после чего руководитель проверяет и утверждает график.
  - Внутри приложения доступен личный раздел **MyShifts** и биржа подмен.
- **FomAI LB (`Learn Base`):** Универсальная платформа знаний и вики-движок:
  - **Два режима:** глобальная энциклопедия (в стиле Wikipedia) и отдельные фэндом-/командные вики-пространства (в стиле Fandom).
  - **Создание статей через Morph AI:** генерация структуры, инфобоксов и ссылок по заметкам, документам или видео с кросс-проверкой фактов по независимым источникам.
  - **Импорт и офлайн:** перенос статей из Wikipedia и Fandom с конвертацией в чистый Markdown / `.ft` и выгрузкой архива для чтения без интернета.
- **FomAI Music:** Музыкальный плеер с поддержкой lossless-аудио, синхронизированных текстов и фирменной витриной **RADIO TAPOK** (*«Найди себя здесь!»*).
- **FomAI Browser:** Браузер со встроенным детектором омоглиф-атак и поддельных доменов.
- **FomAI Office / Paint / Vista / DevStude:** Набор офисных, графических и разработческих инструментов с поддержкой открытых форматов.
